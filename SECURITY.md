# Security policy

Beermat is a desktop app that opens worksheet files, so a malicious worksheet is the main thing to worry about. If you find a way for a `.bbm` or `.xmcd` file, the CLI or the MCP server to do something it shouldn't, please tell us privately.

## Reporting a vulnerability

- Preferred: use **Report a vulnerability** on the repository's Security tab (GitHub private vulnerability reporting).
- Or email **security@beermat.pub**.

Please don't open a public issue for security problems. You'll get a reply within a week. Beermat is maintained by one person in their spare time, so fixes may take a little longer.

## Supported versions

Only the latest release gets security fixes.
